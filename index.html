About

How it works and what is not included.

Scoring. Skills 50% (rarer skills weigh more), title 20%, experience 12%, work mode 9%, salary 9%. Resume ATS score: 50% skill match, 25% keyword match, 25% format checks.

AI features (roadmap, assistant, mock interview, resume suggestions) are answered by Claude through this page and need you to be viewing it on claude.ai.

Not included. Real login and password reset, email alerts and an admin dashboard (these need a secure backend), and verified salary data (needs a licensed API). Your data is saved to your claude.ai account or this browser, so there is no separate login.

Data. Real postings are a dated snapshot with links to the source. Skills for them are inferred from the title.
